문의 · breezeholicmall@gmail.com

보통 2~3일 안에 답장드립니다. 앱 안에서는 설정 → 문의하기로도 보내실 수 있습니다.

구독

구독은 어떻게 해지하나요?

구독은 Apple 계정에서 관리합니다. iPhone 설정 → 맨 위 본인 이름 → 구독 → 「직장인 말씀&기도」 → 구독 취소. 취소해도 이미 결제한 기간이 끝날 때까지는 그대로 보실 수 있습니다.

환불은 어디에 요청하나요?

App Store 결제는 Apple 이 처리하므로 환불도 Apple 에 요청하셔야 합니다. reportaproblem.apple.com 에서 신청하실 수 있습니다.

기기를 바꿨는데 구독이 안 보입니다

같은 Apple 계정으로 로그인한 뒤 앱의 설정 → 구매 복원을 눌러 주세요.

무료로 읽을 수 있는 범위는요?

매일 큐티 365편과 기도수첩·묵상 기록은 전부 무료입니다. 말씀 여정은 목록 위 두 개 여정이 전체 무료이고, 기도문은 상황·마음 각 목록의 위 두 분류가 전체 무료입니다. 그 밖의 여정과 분류는 구독이 필요합니다.

기록

제가 쓴 글은 어디에 저장되나요?

기기 안에만 저장됩니다. 서버가 없어서 저희도 볼 수 없습니다. 기기를 잃어버리면 함께 사라지니, 옮기실 계획이 있으면 아래 내보내기를 써 주세요.

다른 기기로 옮기고 싶습니다

옛 기기에서 설정 → 데이터 내보내기로 파일을 저장하고, 새 기기에서 설정 → 데이터 가져오기로 그 파일을 고르시면 됩니다.

기록을 전부 지우고 싶습니다

설정 → 처음부터 다시 설정에서 지울 수 있고, 앱을 삭제해도 함께 지워집니다. 기도제목 하나만 지우려면 수첩 목록에서 길게 누르거나 상세 화면의 삭제를 누르세요.

앱 사용

알림이 오지 않습니다

iPhone 설정 → 알림 → 직장인 말씀&기도에서 알림 허용이 켜져 있는지 보시고, 앱 안 설정 → 알림 설정에서 시각과 스위치를 확인해 주세요. 집중 모드가 켜져 있으면 알림이 미뤄질 수 있습니다.

영어로 보고 싶습니다

앱 설정 → 말씀·기도 설정 → 언어에서 한국어와 영어를 바꿀 수 있습니다. 큐티·여정·기도문 모두 두 언어로 들어 있습니다.

글씨가 작습니다

설정 → 말씀·기도 설정에서 글자 크기를 세 단계로 고를 수 있습니다.

화면 색이 계속 바뀝니다

배경 하늘은 시간대에 따라 아침·한낮·노을·밤 네 가지로 달라집니다. 하나로 고정하시려면 설정 → 말씀·기도 설정 → 하늘에서 고르세요.

성경 본문은 어느 역본인가요?

한국어는 개역한글(1961), 영어는 World English Bible 입니다. 둘 다 퍼블릭 도메인입니다.
